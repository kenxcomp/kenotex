# 快捷键参考

所有快捷键均可完全自定义。完整参考及默认值请查看 [default.toml](default.toml)。

## Normal 模式

| 按键 | 操作 |
|-----|--------|
| `i` | 进入 Insert 模式 |
| `I` | 在行首进入 Insert 模式 |
| `a` | 进入 Insert 模式（追加） |
| `A` | 在行尾进入 Insert 模式 |
| `o` | 在下方插入新行（自动续接列表前缀） |
| `O` | 在上方插入新行 |
| `v` | 进入 Visual 模式 |
| `V` | 进入 Visual Line 模式 |
| `Ctrl+V` | 进入 Visual Block 模式 |
| `h/j/k/l` | 导航（左/下/上/右） |
| `w/b/e` | 向前/向后/词尾移动一个单词 |
| `0/$` | 行首/行尾 |
| `^` | 跳转到行内第一个非空白字符 |
| `gg/G` | 文件开头/结尾 |
| `Ctrl+U/Ctrl+D` | 向上/向下滚动5行 |
| `x` | 删除字符 |
| `dd` | 删除整行 |
| `dw/de/d$/d0/d^/dG/dg/db` | 配合动作删除（单词/词尾/行尾/行首/首个非空白/文件尾/文件首/前一单词） |
| `yy` | 复制整行到剪贴板 |
| `yw/ye/y$/y0/y^/yG/yg/yb` | 配合动作复制 |
| `p` | 在光标后粘贴（行级操作时在下方粘贴） |
| `P` | 在光标前粘贴（行级操作时在上方粘贴） |
| `gcc` | 切换当前行 HTML 注释（`<!-- -->`） |
| `>` | 增加当前行缩进 |
| `<` | 减少当前行缩进 |
| `u` | 撤销 |
| `Ctrl+R` | 重做 |
| `T` | 切换主题 |
| `/` 或 `f` | 进入搜索模式 |
| `n` | 跳转到下一个搜索匹配 |
| `N` | 跳转到上一个搜索匹配 |
| `Ctrl+L` | 从磁盘重新加载文件（文件被外部修改时使用） |
| `Ctrl+G` | 在外部编辑器中打开缓冲区（`$VISUAL` / `$EDITOR` / `vi`） |
| `Esc` | 返回 Normal 模式 / 清除搜索高亮 |
| `Ctrl+C` 或 `Ctrl+Q` | 退出 |

## Visual 模式

| 按键 | 操作 |
|-----|--------|
| `h/j/k/l` | 扩展选区 |
| `w/b/e` | 按单词向前/向后/词尾扩展 |
| `0/$` | 扩展到行首/行尾 |
| `^` | 扩展到行内第一个非空白字符 |
| `G` | 扩展到文件结尾 |
| `Ctrl+U/Ctrl+D` | 向上/向下扩展选区5行 |
| `d` | 删除选区（同时复制到剪贴板） |
| `y` | 复制选区到剪贴板 |
| `gc` | 切换选中行 HTML 注释 |
| `Space + b/i/x/c/C` | 切换选区加粗/斜体/删除线/行内代码/代码块格式 |
| `(` `)` `[` `]` `{` `}` `'` `"` `` ` `` `*` `~` | 用匹配的配对字符包裹选区 |
| `>` | 增加选中行缩进 |
| `<` | 减少选中行缩进 |
| `gg` | 跳转到文件开头 |
| `Esc` | 退出 Visual 模式 |

## Insert 模式

| 按键 | 操作 |
|-----|--------|
| `(` `[` `{` | 自动插入匹配的关闭括号 |
| `'` `"` | 自动插入匹配的引号 |
| `*` `~` `` ` `` | 自动插入匹配配对；重复输入可扩展（`**\|**`、`~~\|~~`、`` `\|` ``） |
| 关闭字符 | 若光标后已存在则跳过 |
| `:::tag` 后按 `Enter` | 在下一行自动插入关闭 `:::` |
| 配对间按 `Backspace` | 同时删除开始和关闭字符 |
| `Tab` | 插入空格（tab_width 个），列表项行上则缩进整行 |
| `Shift+Tab` | 减少当前行缩进 |
| `Esc` | 返回 Normal 模式 |

## Leader 命令（空格 + 按键）

| 按键 | 操作 |
|-----|--------|
| `空格 + s` | 处理并分发块 |
| `空格 + l` | 打开草稿列表 |
| `空格 + nn` | 创建新笔记 |
| `空格 + q` | 退出 |
| `空格 + h` | 切换快捷键提示栏 |
| `空格 + d` | 切换复选框状态（`- [ ]` ↔ `- [x]`） |
| `空格 + mc` | 在当前行插入复选框（`- [ ] `） |
| `空格 + b` | 切换**加粗**（`**text**`） |
| `空格 + i` | 切换*斜体*（`*text*`） |
| `空格 + x` | 切换~~删除线~~（`~~text~~`） |
| `空格 + c` | 切换行内代码（`` `text` ``） |
| `空格 + C` | 切换代码块（` ``` `） |

## 列表视图

| 按键 | 操作 |
|-----|--------|
| `j/k` | 上下导航 |
| `Enter/l/i` | 打开选中的笔记 |
| `a` | 归档笔记（草稿视图） |
| `r` | 恢复笔记（归档视图） |
| `d` | 删除笔记（需确认） |
| `n` | 创建新笔记 |
| `A` | 切换到归档视图 |
| `/` 或 `f` | 搜索笔记 |
| `空格` | 切换选择 |
| `Esc` | 返回编辑器 |
